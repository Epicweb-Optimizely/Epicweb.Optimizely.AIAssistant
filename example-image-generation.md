# Image generation in Optimizely

This recording shows the image property editor. Enter a prompt, select a generated image, and use **Generate variation** if the configured provider offers that action. **Show all history** displays previous results from the current dialog.

Select an image to use it on the property, or save it under the page's assets. When you open image generation from an asset folder, the editor saves the image to that folder.

The recording uses an earlier provider setup. Configure `ImageModel` and the image provider settings for your installation. See the [configuration guide](configuration.md) and the [release notes](change-log.md) for supported model changes, including the removal of DALL-E 3 support.
